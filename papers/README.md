# BNS postmerger literature archive

This directory is managed by `scripts/download_papers.py`. The seed bibliography is
stored in `seeds.json`; `manifest.json` and `bibliography.bib` are regenerated after
each acquisition run. Every paper directory contains validated metadata and, when
available, its PDF, original arXiv source response, safely extracted source tree,
and an unmodified copy of the probable root TeX file named `main.tex`.

Downloaded binaries and extracted submission trees are intentionally excluded from
Git. Metadata, manifests, bibliographies, and this seed list remain versionable.

Run from the repository root:

```sh
python3 scripts/download_papers.py
python3 scripts/discover_literature.py
python3 -m unittest discover -s tests -v
```

The downloader is serial and waits at least three seconds between requests. Set a
descriptive contact address with `--user-agent` if this archive is regenerated by
someone other than the repository owner.

`candidates.json` is a review queue from the second-pass discovery step. Candidate
papers are never downloaded automatically.
