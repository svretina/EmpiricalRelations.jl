# Scientific background

Binary neutron-star mergers can form a hot, differentially rotating remnant whose
kilohertz gravitational-wave spectrum depends on the binary parameters and the
high-density equation of state (EOS). Numerical-relativity and relativistic
hydrodynamics studies report several distinct observables.

This database separates four kinds of scientific object:

1. **Numerical simulation measurements** transcribed from published tables.
2. **Derived values** calculated from reported quantities under documented algebraic rules.
3. **Empirical fitting relations** calibrated by the original authors.
4. **Predictions** produced by evaluating such fits, which are not raw measurements.

It also separates a Fourier-spectrum maximum from a time-dependent instantaneous
frequency. Similar paper-local symbols are not enough to establish physical identity;
see the [canonical nomenclature](database/frequency_nomenclature.md).
