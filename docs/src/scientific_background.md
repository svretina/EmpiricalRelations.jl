# Scientific background

Binary neutron-star mergers can form a hot, differentially rotating remnant whose
kilohertz gravitational-wave spectrum depends on the binary parameters and the
high-density equation of state (EOS). Numerical-relativity and relativistic
hydrodynamics studies report several distinct observables.

Database records distinguish four types of quantity:

| Type | Definition |
|---|---|
| Numerical simulation measurement | Value transcribed from a published simulation analysis |
| Derived value | Algebraic function of reported quantities |
| Empirical relation | Fitted expression and calibration metadata reported by the authors |
| Prediction | Value obtained by evaluating an empirical relation |

Fourier-spectrum maxima and time-dependent instantaneous frequencies use separate
fields. A shared paper-local symbol does not establish that two quantities have the
same physical definition. The mappings are listed in the
[frequency nomenclature](database/frequency_nomenclature.md).
