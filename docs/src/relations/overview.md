# Empirical relations

The relations inventory describes published fits by predicted quantity, independent
variables, calibration population, applicability domain, residual metrics, and source.
Coefficient values are stored separately and joined by stable relation ID.

These entries are a reviewed catalogue, not yet a callable Julia API. A relation marked
**catalogued** must not be presented as implemented or validated package code. The
browser displays original expressions as text and never evaluates extracted LaTeX.

Open the [interactive catalogue](catalogue.md) to compare available fits.
